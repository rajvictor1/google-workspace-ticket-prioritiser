Workflow opportunity

Every support ticket arrives with the same urgency in the inbox, but not every ticket deserves the same attention. Someone has to read, judge, and route each one — a repetitive decision that burns time and invites bias.

The problem

  • Tickets stack up faster than they can be triaged.
  • Emotional wording ("URGENT!") gets treated as high priority.
  • Repetitive sorting pulls people away from real resolution work.
  • High-priority issues may sit unnoticed among noisy low-priority ones.

The solution

  • Workspace Studio watches the Google Sheet for new ticket rows.
  • Gemini judges impact, not tone, and returns Priority + Category.
  • The flow writes those values back to the same row.
  • Only High-priority tickets trigger a Google Chat notification.

The Four-Filter Framework

Ritesh Hegde’s workflow design breaks any automation into four clear parts: what starts it, what decides it, what changes because of it, and who needs to know.

1

Trigger

A new ticket row appears in the private Google Sheet.

  • Watches the Issue description column.
  • Ignores its own write-back to Priority/Category.
  • Fires within seconds of a new row.
2

Decision

Gemini extracts three fields from the ticket text.

  • Priority: High / Medium / Low
  • Category: Billing, Technical, Policy, Account Access, Other
  • Summary: One line, max 15 words
3

Action

The flow updates the original row with Gemini’s output.

  • Matches row by Timestamp.
  • Writes Priority to the Priority column.
  • Writes Category to the Category column.
4

Handoff

Only High-priority tickets interrupt a person.

  • Check if Priority = High.
  • If true, send a private Google Chat alert.
  • Medium and Low tickets are silent.

How it was built in six steps

Built and verified in Google Workspace Studio using a private Google Sheet as both the source and the destination.

1

Created the private Google Sheet

Columns: Timestamp, Issue description, Reported by, Priority, Category. Imported three sample support tickets from the CSV.

2

Set the trigger

“When a sheet changes” watches the Issue description column in Sheet1. It only fires on real new tickets, not on the flow’s own write-back.

3

Configured Gemini extraction

Passed Issue description and Reported by to Gemini. Asked for priority based on business impact, category from a fixed list, and a one-line summary.

4

Updated the triggering row

Matched the row by Timestamp, then wrote Gemini Priority into the Priority column and Gemini Category into the Category column.

5

Added the high-priority handoff

A “Check if” branch tests whether Priority equals High. Only then does the flow send a private Google Chat notification.

6

Activated and tested

Turned the flow on. Added two live test rows to the sheet. Both completed successfully, producing High/Billing and Low/Account Access classifications.
